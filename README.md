# Helix Client

Premium Tauri launcher foundation for Helix Client.

## Current Phase

Phase 1 - Tauri Launcher Foundation

- Tauri + React + TypeScript launcher shell
- Clean premium Home screen
- Local config save/load through Rust commands
- Target repository structure for launcher, clients, modpacks and shared assets

## Run

```powershell
cd launcher
npm install
npm run dev
```

For the desktop app:

```powershell
cd launcher
npm run tauri:dev
```
